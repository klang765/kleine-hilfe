# Kleine-Hilfe

Shop-Website für digitale PDF-Planer zum Ausdrucken.

Die Seite läuft auf GitHub Pages:

**https://klang765.github.io/kleine-hilfe/**

Die vollständige Übersicht (76 Planer und Pakete) findest du unter [Alle Produkte](https://klang765.github.io/kleine-hilfe/produkte.html).

Die Kauf-Buttons zeigen derzeit „Bald verfügbar“. Zahlung und Download über Lemon Squeezy folgen, sobald der Shop öffnet.

## Auffindbarkeit in Google

Sitemap: https://klang765.github.io/kleine-hilfe/sitemap.xml

robots.txt: https://klang765.github.io/kleine-hilfe/robots.txt

Damit Google die Seite zuordnen kann, muss sie in der [Google Search Console](https://search.google.com/search-console) als URL-Präfix-Property `https://klang765.github.io/kleine-hilfe/` bestätigt werden. Dafür wird der Bestätigungscode aus diesem Konto benötigt – entweder das Meta-Tag (`google-site-verification`) für die Startseite oder die HTML-Datei von Google. Ein Platzhalter reicht nicht.

Danach die Sitemap unter der oben genannten Adresse in der Search Console einreichen.

Hinweis: Google liest `robots.txt` nur an der Domain-Wurzel (`https://klang765.github.io/robots.txt`). Bei dieser Project-Page liegt die Datei unter `/kleine-hilfe/robots.txt`. Deshalb ist das Einreichen der Sitemap in der Search Console der zuverlässige Weg.
